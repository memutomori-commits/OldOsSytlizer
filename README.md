# Retro Bevel — плагин Figma

Бевели в духе Windows 95 для выделенных шейпов: клик по пресету — и у слоя
прямые углы, нужная заливка, Effect Style «Win95 / <name>» и целочисленные
координаты и размеры. Без сборщика: `manifest.json`, `code.js`, `ui.html`
Figma читает как есть.

## Установка

1. Откройте Figma Desktop.
2. **Plugins → Development → Import plugin from manifest…** и выберите `manifest.json`.
3. Плагин появится в **Plugins → Development → Retro Bevel**.

`id` в манифесте — заглушка для локальной разработки; при публикации Figma выдаст свой.

## Использование

1. Выделите один или несколько шейпов (прямоугольники, эллипсы, векторы, фреймы, компоненты, инстансы).
2. Запустите плагин и кликните по пресету. Пока подходящих слоёв нет, пресеты неактивны, а внизу подсказка «Выделите шейп».
3. **Сбросить** убирает эффекты и отвязывает стиль; заливка, обводка и радиус не трогаются.

Каждое применение — отдельный шаг отмены (Ctrl/Cmd+Z).

## Что делает применение

Для каждого выделенного слоя, у которого есть и `fills`, и `effects` (текст пропускается):

- `cornerRadius = 0`;
- обводки убираются; Etched вместо этого ставит обводку #808080, 1 px, inside;
- ставится заливка пресета (у Etched заливки нет);
- создаётся или переиспользуется Effect Style «Win95 / <name>» и привязывается к слою; эффекты стиля синхронизируются с пресетом при каждом применении;
- x, y, width, height округляются до целых. Позиция детей авто-лейаута и размеры HUG/FILL не трогаются.

## Пресеты

Массив `PRESETS` в `code.js`: `{ id, name, fill, effects[], stroke? }`. Тени перечислены как в CSS `box-shadow`: первая сверху; у всех blur 0, spread 0, 100 % непрозрачности. Figma рисует последний эффект массива поверх остальных, поэтому перед записью порядок разворачивается (`toFigmaEffects`).

| Пресет  | Заливка | Тени (x, y, цвет), сверху вниз                                   |
|---------|---------|------------------------------------------------------------------|
| Raised  | #C0C0C0 | inner −1,−1 #0A0A0A; 1,1 #FFFFFF; −2,−2 #808080; 2,2 #DFDFDF      |
| Sunken  | #FFFFFF | inner −1,−1 #FFFFFF; 1,1 #808080; −2,−2 #DFDFDF; 2,2 #0A0A0A      |
| Pressed | #C0C0C0 | inner −1,−1 #FFFFFF; 1,1 #0A0A0A; −2,−2 #DFDFDF; 2,2 #808080      |
| Etched  | нет     | обводка #808080 1 px inside + drop 1,1 #FFFFFF                    |

Чтобы добавить пресет, допишите объект в `PRESETS`: превью UI строит сам, массив приходит в `ui.html` через `postMessage`.
