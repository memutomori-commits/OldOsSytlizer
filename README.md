# Retro Bevel — плагин Figma

Бевели в духе Windows 95 для выделенных шейпов: клик по пресету — и у слоя
прямые углы, нужная заливка, Effect Style «Win95 / <name>» и целочисленные
координаты и размеры. Сборщика нет: Figma читает `manifest.json`, `code.js`
и `ui.html` как есть.

## Установка вручную (Figma Desktop)

1. **Plugins → Development → Import plugin from manifest…** и выберите `manifest.json`.
2. Плагин появится в **Plugins → Development → Retro Bevel**.

`id` в манифесте — заглушка для локальной разработки; при публикации Figma выдаст свой.
Команда в `relaunchButtons` равна `id`: так плагин получает кнопку повторного запуска
в панели свойств, а код не зависит от способа установки.

## Установка через Figma MCP

Если у Claude подключён Figma MCP, плагин ставится без Figma Desktop: он попадает
в библиотеку аккаунта как generative plugin. Манифест в этом случае генерирует Figma,
а через MCP передаются `code.ts` и `ui.html` без изменений. Готовый промт лежит
в `docs/mcp-install-prompt.md`.

## Использование

1. Выделите один или несколько шейпов (прямоугольники, эллипсы, векторы, фреймы, компоненты, инстансы).
2. Запустите плагин и кликните по пресету. Пока подходящих слоёв нет, пресеты неактивны, а внизу подсказка «Выделите шейп».
3. **Сбросить** убирает эффекты и отвязывает стиль; заливка, обводка и радиус не трогаются.

Каждое применение — отдельный шаг отмены (Ctrl/Cmd+Z).

## Что делает применение

Для каждого выделенного слоя, у которого есть и `fills`, и `effects` (текст пропускается):

- `cornerRadius = 0`;
- обводки убираются; Etched вместо этого ставит обводку #808080, 1 px, inside;
- ставится заливка пресета (у Etched заливки нет);
- создаётся или переиспользуется Effect Style «Win95 / <name>» и привязывается к слою; эффекты стиля синхронизируются с пресетом при каждом применении;
- x, y, width, height округляются до целых. Позиция детей авто-лейаута и размеры HUG/FILL не трогаются.

## Пресеты

Массив `PRESETS` в `code.ts`: `{ id, name, fill, effects[], stroke? }`. Тени перечислены как в CSS `box-shadow`: первая сверху; у всех blur 0, spread 0, 100 % непрозрачности. Figma рисует последний эффект массива поверх остальных, поэтому перед записью порядок разворачивается (`toFigmaEffects`).

| Пресет  | Заливка | Тени (x, y, цвет), сверху вниз                                   |
|---------|---------|------------------------------------------------------------------|
| Raised  | #C0C0C0 | inner −1,−1 #0A0A0A; 1,1 #FFFFFF; −2,−2 #808080; 2,2 #DFDFDF      |
| Sunken  | #FFFFFF | inner −1,−1 #FFFFFF; 1,1 #808080; −2,−2 #DFDFDF; 2,2 #0A0A0A      |
| Pressed | #C0C0C0 | inner −1,−1 #FFFFFF; 1,1 #0A0A0A; −2,−2 #DFDFDF; 2,2 #808080      |
| Etched  | нет     | обводка #808080 1 px inside + drop 1,1 #FFFFFF                    |

Чтобы добавить пресет, допишите объект в `PRESETS`: превью UI строит сам, массив приходит в `ui.html` через `postMessage`.

## Разработка

Исходник логики — `code.ts`: строгий TypeScript с типами `@figma/plugin-typings`,
проходит `tsc --strict` и ESLint (typescript-eslint с проверкой типов плюс правила
`@figma/eslint-plugin-figma-plugins`). `code.js` сгенерирован из него и закоммичен,
чтобы ручная установка работала без `npm`. После правок в `code.ts`:

    npm install
    npm run build

Это только `tsc` без бандлера. `ui.html` — обычный HTML без зависимостей.

# Desktop Scatter — второй плагин (папка `desktop-scatter/`)

Раскидывает ярлыки Win98 по выделенному прямоугольнику или фрейму, как по рабочему
столу. Ярлыки — инстансы компонент-сета **«Desktop Icon»** из файла (страница
CLUBS / DESIGN KIT, блок 05 Desktop Icons): семь пиксельных иконок, стрелка ярлыка
(свойство Shortcut) и синяя подсветка подписи (Selected).

## Установка

Так же, как Retro Bevel: **Plugins → Development → Import plugin from manifest…** и
выберите `desktop-scatter/manifest.json`. Или через Figma MCP как generative plugin:
файлы `desktop-scatter/code.ts` и `desktop-scatter/ui.html` передаются без изменений.

## Использование

1. Выделите прямоугольник (результат ляжет поверх него) или фрейм (результат ляжет внутрь).
2. Задайте сид и параметры, нажмите **Раскидать**. Стрелки ◀ ▶ и «Случайный» меняют
   сид и сразу перерисовывают стол; галка «сразу» делает то же для остальных параметров.
3. Результат — фрейм `Desktop scatter · seed N` с инстансами. Пока он выделен, плагин
   помнит его стол и параметры: следующий запуск заменяет фрейм, а не плодит копии.

| Параметр | Что делает |
|----------|------------|
| Сет | Любой компонент-сет файла (список собирается по всем страницам, ↻ обновляет); по умолчанию «Desktop Icon» |
| Сид | Одинаковый сид и параметры → одинаковая раскладка (mulberry32) |
| Ярлыков | Сколько инстансов положить (до 200; сколько уместится). Варианты берутся по кругу в перемешанном порядке: пока ярлыков не больше, чем вариантов, повторов нет |
| Масштаб % | `rescale` инстанса; 50 % = иконка 112 px |
| Зазор, Поля | Расстояние между ячейками и от края стола |
| Хаос | 0 — столбцами от левого верхнего угла, как расставляет Windows; 100 — по всему столу. Между — смесь аккуратной и случайной позиции каждого ярлыка |
| По сетке | Те же позиции привязываются к ячейкам сетки, занятые ячейки обходятся по кольцам; без галки — свободные позиции без пересечений |
| Стрелка ярлыка, один выделен | Свойства Shortcut и Selected у инстансов, если они есть у сета |
| Подписи | Пул строк; пусто — подписи вариантов. Нужен шрифт подписи (PP Mondwest) |

Каждый запуск — отдельный шаг отмены. Выбранный сет запоминается в plugin data документа.

## Разработка

`npm run build` собирает оба плагина (`code.ts → code.js` в корне и в `desktop-scatter/`).
