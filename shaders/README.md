# Шейдеры Dither и CRT Display

Исходники двух шейдер-эффектов из библиотеки Figma аккаунта (`developer@brickagency.email`),
которые ставятся на слои поверх постов @Clubs. Шейдеры живут в Figma, а не в этом репо:
здесь копия исходников и таблица пресетов, чтобы правки и пресеты не терялись.

| Шейдер      | id в библиотеке Figma                  | Файл                 |
|-------------|----------------------------------------|----------------------|
| Dither      | `45b27e28-4b6b-4a00-8aa0-26e7a719a33d` | `shaders/dither/main.ts` |
| CRT Display | `f7a1faf4-6a51-4ee2-ab42-0e5b971b62d1` | `shaders/crt/main.ts`    |

(В библиотеке есть ещё первопартийные «Dither» и «CRT Screen» от Figma — это другие шейдеры.)

## Пресеты

У шейдеров в Figma нет своей памяти: эффект получает только значения своих контролов.
Поэтому «свой пресет» устроен двумя способами.

### 1. Список `Preset`

Первый контрол в панели эффекта. `Custom (sliders)` — работают обычные слайдеры.
Любой другой пункт подставляет значения из таблицы, зашитой в шейдер, но только в те
контролы, которые стоят на дефолте. Сдвинутый слайдер побеждает пресет, так что пресет
можно донастраивать; чтобы вернуть параметру значение пресета, поставьте слайдер
обратно на дефолт. Таблица — `shaders/presets.json`. Чтобы добавить или поменять пресет:

1. Допишите объект в массив `dither` или `crt`: `{ "name": "…", "values": { … } }`.
   Ключи — имена параметров шейдера (см. `defineProperties` в `main.ts`),
   цвета — строкой `#RRGGBB`. Ключ можно опустить: тогда для него останется слайдер.
2. `node shaders/bake-presets.js` — перепишет блоки между маркерами `PRESETS-BEGIN/END`
   и `PRESET-OPTIONS-BEGIN/END` в обоих `main.ts`.
3. Загрузите `main.ts` в Figma через MCP `update_shader` (id из таблицы выше, `kind: "effect"`),
   либо попросите Claude в проекте.

Не переставляйте уже существующие пресеты: слои в файлах помнят пресет по номеру,
новые добавляйте в конец.

### 2. Поле `Preset code`

Последний контрол, текстовое поле. Туда пишется строка вида

```
algorithm=2, levels=3, cellSize=4, dark=#0F380F
```

Пары `ключ=значение` через запятую, точку с запятой или перенос строки, регистр ключей
не важен, цвета — `#RRGGBB`. Указанные ключи перекрывают всё остальное, и слайдеры, и выбранный пресет;
неуказанные остаются как есть. Так настройку можно сохранить в заметке и вставить
на любой слой без пересборки шейдера. Текущие значения слайдеров в строку шейдер
выписать не может — её собирают руками по панели.

## Параметры

Dither: `algorithm` (0 Bayer 2×2, 1 Bayer 4×4, 2 Bayer 8×8, 3 gradient noise, 4 white noise,
5 halftone), `mode` (0 color, 1 luma, 2 mono, 3 two-tone), `cellSize`, `levels`, `strength`,
`angle`, `dark`, `light`.

CRT Display: `pattern` (0 RGB, 1 BGR, 2 mono), `pixelSize`, `softness`, `pitch`, `tint`,
`gapWidth`, `gapDark`, `scanlines`, `scanPitch`, `fringe`, `glow`, `glowRadius`, `gain`,
`curvature`, `vignette`, `strength`.
