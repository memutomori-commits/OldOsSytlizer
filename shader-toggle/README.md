# Shader Toggle — плагин Figma

Одной кнопкой выключает и включает все шейдерные эффекты (Dither и любые другие
SHADER-эффекты, а также шейдерные заливки) на текущей странице или в выделении.
Нужен, чтобы быстро посмотреть макет «без дизеринга» и вернуть всё обратно.

- **Переключить шейдеры** — если хоть один включён, выключает все; иначе включает все.
- **Выкл / Вкл** — принудительно.
- **Где** — вся страница или выделение вместе с вложенными слоями.
- На слоях-линзах вместе с SHADER переключается и эффект Glass, чтобы линза гасла целиком.
- Слои, у которых эффекты приходят из Effect Style, не трогаются (стиль общий); плагин показывает, сколько их.
- Каждое применение — отдельный шаг отмены (Ctrl/Cmd+Z).

Ставится двумя способами:

- **Вручную в Figma Desktop**: Plugins → Development → Import plugin from manifest… → `shader-toggle/manifest.json`.
  С 2026-11-13 `ui.html` написан на обычном HTML (панель Win95 в Shadow DOM, как у Retro Bevel), так что ручной импорт работает.
- **Через Figma MCP** как generative plugin: передать `code.ts` и `ui.html` без изменений (manifest генерирует Figma).
  В библиотеке аккаунта memut (с 2026-11-13) плагин под id `32c5d7a4-7bfe-4251-93d8-ec3f2a87f2b9`
  (на старом аккаунте был `8af98895-f45a-4267-a00e-32775a8f65ac`).

Сборка: `npx tsc -p shader-toggle/tsconfig.json` (или `npm run build` в корне).
