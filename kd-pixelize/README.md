# KD Pixelize — плагин Figma

Пикселизация картинки KD-деревом: кадр режется на прямоугольные блоки разного размера —
мелкие там, где много деталей (лицо, руки, край силуэта), крупные на ровных участках
(куртка, стена). Плюс детект людей: плагин находит людей на картинке, вы кликаете по
нужному — и пикселизируется только он, фон остаётся нетронутым.

## Как пользоваться

1. Выделите слой с картинкой (прямоугольник с image-заливкой, фрейм, что угодно, что можно
   экспортировать). Плагин сам выгрузит его в превью. Или нажмите **Файл…** и откройте
   картинку с диска — тогда результат ляжет новым слоем в центр экрана.
2. **Найти людей** — при первом нажатии подгружается модель (TensorFlow.js + BodyPix,
   около 5 МБ из CDN), потом поиск занимает пару секунд. Найденные люди обводятся рамками
   с номерами; первый выбран сразу. Клик по человеку на превью или по кнопке «Человек N»
   включает/выключает его. Пока никто не выбран, пикселизируется вся картинка.
   Галочка **Наоборот** пикселизирует всё, кроме выбранных.
3. Крутите слайдеры, превью пересчитывается на лету:
   - **Мин. блок** — размер самого мелкого блока и шаг сетки, на которую ложатся разрезы;
   - **Макс. блок** — крупнее этого блок не бывает, даже если он однотонный;
   - **Порог детализации** — допустимая ошибка цвета внутри блока (RMSE по каналам);
     ниже порог — больше мелких блоков;
   - **Детали по краю** — насколько сильно граница силуэта дробит блоки;
   - **Край силуэта**: «Блоками» — блок закрашивается целиком, если больше половины
     его накрыто маской (ступенчатый край, как на референсе), «По маске» — закрашиваются
     только пиксели внутри маски (ровный край).
4. **Применить**: «Новый слой рядом» кладёт результат прямоугольником справа от источника
   того же размера, «Заменить заливку» пишет картинку в заливку выделенного слоя.
   Каждое применение — отдельный шаг отмены.

Размер блоков по умолчанию подбирается под картинку (~1/75 длинной стороны), пока вы сами
не сдвинули «Мин. блок» или «Макс. блок».

## Как это устроено

- `code.ts` — песочница: выгружает выделенный слой в PNG (длинная сторона не больше
  2048 px), по сообщению `apply` создаёт `figma.createImage` и либо прямоугольник рядом
  с источником, либо заменяет его заливку.
- `ui.html` — вся обработка. `kdPixelize(imageData, mask, params)`: регион делится по
  длинной стороне в точке, где суммарная ошибка двух половин минимальна (статистика по
  колонкам/строкам за один проход, без интегральных картинок), пока ошибка внутри блока
  выше порога или блок крупнее максимума. Позиции разрезов кратны минимальному блоку,
  поэтому блоки ложатся на общую сетку. Цвет блока — среднее только по пикселям маски,
  чтобы фон не подмешивался в силуэт. Маска входит в ошибку отдельным слагаемым
  («Детали по краю»), поэтому у границы силуэта блоки мельчают.
- Детект: `bodyPix.segmentMultiPerson` (MobileNetV1 0.75, stride 16, квантизация 2 байта)
  на уменьшенной копии (длинная сторона 640 px), маски тянутся обратно через canvas со
  сглаживанием и порогом. Если модель не разделила людей, берётся `segmentPerson` и
  связные компоненты маски. Скрипты грузятся с `cdn.jsdelivr.net`, веса —
  с `storage.googleapis.com`; без сети работает только пикселизация всей картинки.

## Установка

Через Figma MCP: `update_generative_plugin` с файлами `code.ts` и `ui.html`, как описано
в `docs/mcp-install-prompt.md` для Retro Bevel. Манифест плагина из библиотеки Figma
без `networkAccess`, то есть сеть не ограничена — CDN доступен.

Вручную: `npx tsc -p kd-pixelize/tsconfig.json`, затем Plugins → Development →
Import plugin from manifest… → `kd-pixelize/manifest.json`. В этом манифесте домены CDN
перечислены в `networkAccess.allowedDomains`.

## Тест без Figma

`ui.html` открывается в обычном браузере: `window.__kd` даёт `kdPixelize`, `detectPeople`
и `state`. Картинку можно подсунуть сообщением `{ pluginMessage: { type: 'image', bytes } }`,
результат уходит сообщением `apply` в `parent`.
