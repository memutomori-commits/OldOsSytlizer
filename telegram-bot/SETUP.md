# Как запустить бота Clubs News: пошаговая инструкция

Бот берёт PNG-фреймы со страницы Figma **CLUBS / TELEGRAM READY** и публикует их в Telegram-канал
по манифесту `posts.json`. Ниже полный путь от нуля до первого поста в тестовом канале.

## 0. Что понадобится

- Компьютер с Python 3.9 или новее. Проверка в терминале: `python --version`
  (Windows: `py --version`, macOS/Linux: `python3 --version`). Если Python нет, ставьте с
  python.org; на Windows при установке отметьте «Add python.exe to PATH».
- Git, либо просто скачайте ZIP ветки с GitHub.
- Доступ к файлу Figma `clubs_main` и права администратора в тестовом канале.
- Telegram на телефоне или Telegram Desktop.

Во всех командах ниже `python` на Windows можно заменить на `py`, на macOS/Linux на `python3`.

## 1. Скачать код

```bash
git clone https://github.com/memutomori-commits/OldOsSytlizer.git
cd OldOsSytlizer
git checkout claude/telegram-clubs-news-templates-smm32d
cd telegram-bot
```

Без git: на GitHub переключите ветку на `claude/telegram-clubs-news-templates-smm32d`,
Code → Download ZIP, распакуйте, откройте терминал в папке `telegram-bot`.

Сторонние библиотеки не нужны, `pip install` не требуется.

## 2. Создать бота в BotFather

1. В Telegram откройте [@BotFather](https://t.me/BotFather), отправьте `/newbot`.
2. Имя бота: любое, например `Clubs News Preview`.
3. Username: должен заканчиваться на `bot`, например `clubs_preview_bot`.
4. BotFather пришлёт токен вида `123456789:AAH…`. Это пароль от бота, никому не показывайте.

## 3. Добавить бота в тестовый канал

Ссылка-приглашение `t.me/+JkLoriYAQyMzNWFi` работает только для людей, бота по ней не добавить.
Нужно добавить его администратором:

1. Откройте канал → нажмите на название → **Администраторы** → **Добавить администратора**.
2. Найдите бота по username (`@clubs_preview_bot`) и выберите его.
3. Включите право **Публикация сообщений** (Post messages). Остальные права можно выключить.
4. Сохраните.

## 4. Заполнить .env

```bash
cp .env.example .env        # Windows: copy .env.example .env
```

Откройте `.env` в любом текстовом редакторе и впишите значения после знака `=`, без кавычек
и без комментариев в той же строке:

```
BOT_TOKEN=123456789:AAH0abcDEFghij-klmnopQRSTuvwxyz012345
CHANNEL_ID=
OWNER_ID=
```

`BOT_TOKEN` — настоящий токен из BotFather (пример выше вымышленный), `CHANNEL_ID` заполним на
шаге 5, `OWNER_ID` — ваш user id, чтобы команды в личке принимались только от вас. Если оставить
плейсхолдер из примера, бот остановится с сообщением «BOT_TOKEN выглядит неверно».

Свой user id можно узнать у бота [@userinfobot](https://t.me/userinfobot) или позже командой
`/chatid` в личке с вашим ботом (режим `serve`, шаг 9). Если `OWNER_ID` пустой, команды принимаются
от любого, кто напишет боту.

## 5. Узнать CHANNEL_ID

Способ А:

1. После добавления бота опубликуйте в канале любое сообщение, хоть «test». Старые сообщения
   бот не видит, нужно новое.
2. Выполните:

   ```bash
   python bot.py discover
   ```

   Появятся строки вида `-1001234567890  [channel]  Название канала`. Скопируйте id
   в `CHANNEL_ID` в `.env`. У приватных каналов id всегда начинается с `-100`.

Способ Б: запустите `python bot.py serve`, перешлите боту в личку любой пост из канала и ответьте
на пересланное сообщение командой `/chatid`. Бот покажет id канала.

Если `discover` ничего не показал: проверьте, что бот действительно администратор с правом
публикации, и опубликуйте ещё одно сообщение в канале.

## 6. Подготовить картинки из Figma

### 6.1. Вернуть шрифты (один раз)

На странице **CLUBS / TELEGRAM READY** часть текстов набрана Handjet Bold, потому что шрифты
PP Mondwest и PP NeueBit недоступны через API. Такие слои названы `⚠ FONT: set back to …`.

1. В панели слоёв нажмите Ctrl/Cmd+F и введите `⚠ FONT`.
2. Выделите найденные слои и поставьте шрифт из названия слоя: заголовки обложек #152 и #166 →
   **PP Mondwest Regular**, поля досье #203 и #163 → **PP NeueBit Bold**.
3. Текст уже на месте, менять нужно только шрифт.

### 6.2. Экспорт вручную (надёжный способ)

На всех 32 фреймах постов уже стоят настройки экспорта PNG 1x, а с секций и внутренних слоёв они
сняты. Поэтому выгрузить всё можно одной кнопкой:

1. Откройте страницу **CLUBS / TELEGRAM READY** и нажмите **Ctrl+Shift+E** (меню File → Export…).
   В списке должно быть ровно 32 слоя: 6 Clubs Scan, 3 One Image Post, 2 Dossier, 3 Carousel Cover,
   11 Carousel Post, 3 Video Post, 4 Twitter Repost.
2. Нажмите **Export** и выберите пустую папку, например `Downloads\clubs_export`. Figma сложит файлы
   по подпапкам из имён фреймов, это нормально.
3. Разложите файлы по местам одной командой:

   ```bash
   python bot.py import "C:\Users\you\Downloads\clubs_export"     # Windows
   python bot.py import ~/Downloads/clubs_export                  # macOS/Linux
   python bot.py check
   ```

   `import` находит номер поста по `#253` в имени файла, номер слайда по `— 02`, обложку по слову
   Cover, и копирует всё в `assets/<id>/<file>` с именами из `posts.json`. `check` должен показать
   ✅ у всех 21 постов.

Почему не работает Ctrl+A: оно выделяет только секции верхнего уровня, а не фреймы внутри них.
Если нужно выделить фреймы руками: кликните по секции, нажмите **Enter** (выделятся её дети),
затем в правой панели Export → Export N layers. Новый фрейм, добавленный позже, получит настройки
экспорта через правую панель Export → «+» → PNG 1x, после этого он тоже попадёт в список Ctrl+Shift+E.

### 6.3. Экспорт через Figma REST (альтернатива)

1. Figma → аватар → Settings → Security → Personal access tokens → Generate new token,
   права «File content: Read only».
2. Впишите токен в `.env`: `FIGMA_TOKEN=figd_...`
3. Выполните `python export_figma.py`, затем `python bot.py check`.

Облачный рендер Figma может подменить локальные шрифты PP Mondwest и PP NeueBit. Откройте пару
PNG из `assets/` и сравните с Figma Desktop; если шрифты не те, используйте ручной экспорт.

## 7. Видео

- #161 и #285: при первой публикации бот попробует скачать видео по ссылке из `posts.json`.
  Ссылки из превью t.me живут недолго, поэтому надёжнее положить файлы руками: в Telegram Desktop
  откройте пост → меню ⋯ → Сохранить как → `assets/161/video.mp4` и `assets/285/video.mp4`.
- #224: ссылки нет, положите `assets/224/video.mp4` вручную.
- Без файла бот отправит заглушку как обычное фото с пометкой длительности.
- Лимит Bot API на загрузку видео: 50 МБ.

## 8. Публикация

```bash
python bot.py list                 # все посты и статус файлов
python bot.py post 253 --dry-run   # план без отправки
python bot.py post 253             # транзакция: одно фото с подписью
python bot.py post 411             # карусель: альбом, обложка первой, затем слайды
python bot.py post 161             # видео: PNG-заглушка как обложка видео
python bot.py post all --delay 5   # все 21 пост подряд с паузой 5 секунд
```

Что происходит при отправке (режим `rich_mode: auto` в `posts.json`):

- карусели (#411, #152, #166) уходят как **Rich Message**: листаемая галерея с обложкой первой,
  заголовок, текст и подвал в одном сообщении, как у нативных постов канала;
- одиночные посты (транзакции, Paint, досье, твиттер) уходят как фото с подписью и подвалом;
  если подпись длиннее 1024 символов (#163), пост тоже уходит как Rich Message одним сообщением;
- видео уходит с PNG в качестве cover (Bot API 8.3+); если сервер не принял cover, PNG ставится
  как thumbnail; в режиме `rich_mode: all` видео идёт rich-блоком `video` с той же обложкой;
- текст берётся из `caption_html` с исходной вёрсткой канала: жирный, ссылки, обычные и
  раскрывающиеся цитаты, поэтому пост выглядит как в @clubs; подвал добавляется из `footer_html`;
- `python bot.py list` показывает, каким способом уйдёт каждый пост: `rich` или `classic`.

Rich Messages отображаются в актуальных версиях Telegram (лето 2026 и новее). Если сервер отвергнет
`sendRichMessage`, бот сам отправит пост классическим альбомом.

## 9. Режим бота в личке

```bash
python bot.py serve
```

Окно терминала должно оставаться открытым. Напишите боту в личку:

- `/list` — посты и статус файлов
- `/post 253` — опубликовать пост в канал
- `/post all` — опубликовать все
- `/check` — проверить файлы
- `/chatid` — id чата; в ответ на пересланное сообщение покажет id канала
- `/ping` — проверка связи

Остановить: Ctrl+C. Запуск в фоне: Windows `start /min py bot.py serve` или Планировщик заданий;
Linux `nohup python3 bot.py serve > bot.log 2>&1 &`. Нельзя запускать два экземпляра `serve` с одним
токеном одновременно, Telegram вернёт ошибку `terminated by other getUpdates request`.

## 10. Добавить новый пост

1. Оформите фрейм на странице TELEGRAM READY по шаблону с MAIN 3, в имя фрейма включите номер
   поста, например `Clubs Scan / #480 ETH — …`.
2. Добавьте объект в `posts.json`: `id`, `type`, `title`, `caption_html` (разметка Telegram-HTML без
   подвала; можно скопировать из превью `t.me/clubs/<id>?embed=1`) или просто `caption`, `media` с
   `node` (id фрейма: правый клик по фрейму → Copy link, id в конце ссылки после `node-id=`,
   дефис заменить на двоеточие) и `file`.
3. Экспортируйте PNG, выполните `python bot.py import …`, `python bot.py check`,
   `python bot.py post 480`.

## 11. Если что-то пошло не так

| Сообщение | Причина и что делать |
|---|---|
| `Unauthorized` | Неверный `BOT_TOKEN`. Скопируйте токен из BotFather заново. |
| `chat not found` | Неверный `CHANNEL_ID` или бот не добавлен в канал. Повторите шаги 3 и 5. |
| `not enough rights` / `CHAT_WRITE_FORBIDDEN` | У бота нет права «Публикация сообщений». |
| `нет файлов: assets/…` | PNG не экспортированы или лежат не там. `python bot.py import …`, затем `check`. |
| `Request Entity Too Large` | Видео больше 50 МБ. Сожмите или опубликуйте вручную. |
| `PHOTO_INVALID_DIMENSIONS` | Сумма ширины и высоты PNG больше 10000 px. Экспортируйте в 1x, не 2x. |
| `terminated by other getUpdates request` | Запущено два экземпляра `serve`. Оставьте один. |
| `discover` ничего не показывает | Нет новых сообщений в канале после добавления бота. Опубликуйте ещё одно. |

Тесты без сети: `python -m unittest discover -s tests -v`.
