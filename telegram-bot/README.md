# Clubs News — бот для публикации оформленных постов

Публикует в Telegram-канал посты, оформленные по шаблонам Figma (страница
**CLUBS / TELEGRAM READY** файла `clubs_main`). Один скрипт на стандартной библиотеке
Python 3.9+, без зависимостей.

Что умеет:

- **фото** — одиночный PNG-фрейм с подписью (транзакции Clubs Scan, Paint-посты, досье, репосты из твиттера);
- **альбом** — карусель: обложка-заглушка первой, затем слайды (`sendMediaGroup`, до 10 элементов);
- **видео** — PNG-заглушка ставится обложкой видео (`cover`, Bot API 8.3+; если сервер не принял — как `thumbnail`),
  а если видео нет — заглушка уходит как фото;
- длинные тексты (>1024 символов) — подпись = заголовок, полный текст отдельным сообщением-ответом;
- к каждому посту добавляется подвал канала (`footer_html` в `posts.json`).

## Быстрый старт

1. Создайте бота у [@BotFather](https://t.me/BotFather), скопируйте токен.
2. Добавьте бота **администратором** тестового канала (право «Публикация сообщений»).
3. Настройки:

   ```bash
   cd telegram-bot
   cp .env.example .env     # впишите BOT_TOKEN
   python bot.py discover   # покажет chat_id канала после любого поста в нём → CHANNEL_ID в .env
   ```

   Узнать id канала можно и так: перешлите любой пост канала боту в личку и ответьте на него
   командой `/chatid` (в режиме `serve`).

4. Положите PNG-фреймы в `assets/<id>/<file>` (имена — в `posts.json`). Два способа:
   - **вручную**: на странице TELEGRAM READY нажать Ctrl+Shift+E (File → Export…): настройки экспорта
     PNG 1x уже стоят на всех 32 фреймах постов; экспорт в пустую папку, затем
     `python bot.py import <папка>` разложит файлы по `assets/` сам
     (номер поста берётся из `#253` в имени файла, слайды из `— 02`, обложка по слову Cover);
   - **через REST**: `FIGMA_TOKEN=... python export_figma.py` (id фреймов уже прописаны в `posts.json`).
     Внимание: шрифты PP Mondwest / PP NeueBit локальные, облачный рендер может их подменить —
     сверьте результат с тем, что видно в Figma Desktop.

5. Проверка и публикация:

   ```bash
   python bot.py import ~/Downloads/clubs_export   # разложить экспорт из Figma по assets/
   python bot.py check              # все ли файлы на месте
   python bot.py post 253 --dry-run # план без отправки
   python bot.py post 253           # один пост
   python bot.py post all --delay 5 # все посты подряд
   python bot.py serve              # бот в личке: /list, /post <id>, /post all, /check, /chatid
   ```

   В `.env` можно задать `OWNER_ID` (ваш user id, через запятую несколько) — тогда команды в личке
   принимаются только от вас.

## posts.json

```json
{
  "figma_file_key": "nauetSvKmcBNlynjR3p4Rp",
  "footer_html": "🙂Top news: <a href=\"https://t.me/clubs\">@clubs</a>\n…",
  "posts": [
    {
      "id": "411",                        // номер поста в канале (t.me/clubs/411)
      "type": "carousel",                 // transaction | one_image | dossier | carousel | video | twitter
      "title": "Tectonic exploit $75M",   // для списка
      "caption": "Текст поста…",          // без подвала; HTML экранируется автоматически
      "append_footer": true,              // необязательно, по умолчанию true
      "media": [                          // порядок = порядок в альбоме, первый — обложка
        {"node": "736:13865", "file": "cover.png"},
        {"node": "736:13889", "file": "slide_01.png"}
      ],
      "video": {"file": "video.mp4", "url": "https://…", "duration": "2:05"}   // только для type=video
    }
  ]
}
```

- `node` — id фрейма в Figma (нужен только `export_figma.py`); `file` — имя PNG в `assets/<id>/`.
- Для `video`: файл берётся из `assets/<id>/video.mp4`, при отсутствии скачивается по `url`
  (ссылки превью t.me живут недолго — надёжнее положить файл руками). Нет ни файла, ни url —
  публикуется фото-заглушка с пометкой длительности.
- Чтобы добавить новый пост: оформить фрейм в Figma, добавить объект в `posts`, экспортировать PNG.
