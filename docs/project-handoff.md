## 1. Общая задача

Создать айдентику Telegram-канала о криптобезопасности в стиле Retro OS:
интерфейсы Windows 95 и Classic Mac OS (System 7). Пользователь общается
по-русски, коротко, ждёт результата, а не обсуждения вариантов.

Рабочая метафора (предложение, с пользователем не утверждалось): канал как
старая операционная система. Пост — окно; предупреждение о скаме — диалог
«Warning» с иконкой восклицательного знака; разбор взлома — «Error» или
синий экран; инструкция — мастер установки с кнопками «Назад / Далее»;
чек-лист — окно с чекбоксами; адреса и хэши — терминал или моноширинный блок.

## 2. Что уже сделано

### 2.1 Плагин Figma «Retro Bevel» (готов, работает)

Ставит на выделенные шейпы бевели Windows 95 одним кликом. Исходники в корне
репозитория: `code.ts` (строгий TypeScript, типы `@figma/plugin-typings`),
`code.js` (сгенерирован `npm run build`, закоммичен), `ui.html` (панель 300×240
в стиле Win95, живёт в Shadow DOM, чтобы стили PropsKit библиотечной сборки
Figma её не ломали), `manifest.json`.

Что делает клик по пресету на каждом выделенном слое с `fills` и `effects`
(текст пропускается): `cornerRadius = 0`; обводки убираются (у Etched ставится
#808080, 1 px, inside); ставится заливка пресета; создаётся или
переиспользуется Effect Style «Win95 / <name>» и привязывается к слою; x, y,
width, height округляются до целых, авто-лейаут и HUG/FILL не трогаются.
Кнопка «Сбросить» снимает эффекты и отвязывает стиль. Каждое применение —
отдельный шаг отмены.

Два способа установки:

- Вручную: Figma Desktop → Plugins → Development → Import plugin from
  manifest → `manifest.json`. Id в манифесте (`1483759264018273645`) —
  заглушка для локальной разработки.
- Через Figma MCP как generative plugin (без Figma Desktop): готовый промт
  лежит в `docs/mcp-install-prompt.md`. Манифест в этом случае генерирует
  Figma, через MCP передаются только `code.ts` и `ui.html` без изменений.
  Сборка Figma компилирует TypeScript строго и гоняет ESLint, поэтому
  `@ts-nocheck` и «улучшения» кода недопустимы.

Чтобы добавить пресет, дописывается объект в массив `PRESETS` в `code.ts`
(`{ id, name, fill, effects[], stroke? }`), затем `npm install && npm run
build`. Превью в панели строится само из тех же данных.

### 2.2 Дизайн-кит в Figma (существует, принадлежит пользователю)

Файл `nauetSvKmcBNlynjR3p4Rp`, страница «CLUBS / DESIGN KIT». Известные
компоненты (по скиллу `brick`):

- «Window (Classic Mac) / Customizable — free resize», нода `74:329114`.
  Резиновое окно: VERTICAL auto-layout, адаптивный заголовок с полосами,
  статус-бар, контент FILL×FILL, 9-slice бевел на констрейнтах.
  Шрифты PP Mondwest Regular и PP NeueBit Bold. Базовая единица U = 1,056 px.
- «Win95 / Window» с вариантами Default/Small, вложенные «Title Bar» и
  «Control Button» (варианты `Glyph=…`). Шрифт Inter Regular, сетка — целые
  пиксели. Проверено: бар 24 / 36 / 56 px даёт кнопки 20×17 / 34×29 / 57×49
  и кегль 12 / 18 / 28; минимум окна Default 144×81.

Открытый вопрос: это и есть рабочий файл айдентики канала или отдельный кит.
Спросить пользователя перед тем, как что-то туда класть.

### 2.3 Скилл `brick` (есть в аккаунте)

Команда `brick` + ссылка на фрейм: переводит статичный фрейм в резиновый
авто-лейаут по образцу Classic Mac Window, доводит готовые компоненты,
собирает новые окна. Правила скилла: кирпичи снизу вверх, работа на копии
«… (brick)», обязательный тест ресайза, адаптивный заголовок с кнопками
(FILL по высоте + lock aspect ratio, глиф SCALE/SCALE, заголовок TRUNCATE).
Перед `use_figma` скилл требует загрузить `skill://figma/figma-use/SKILL.md`.

Не путать с проектом «HIGH IQ MONEY» (YouTube-канал): его скиллы
(`paranoia-*`, `thumbnail-title-lab`, `stillshot-animator` и др.) тоже
синхронизированы в аккаунт, но к этой задаче не относятся.

## 3. Визуальная система, уже зафиксированная в коде и ките

Палитра Win95 (из `ui.html` и `PRESETS`):

| Роль     | HEX     | Где используется                              |
|----------|---------|-----------------------------------------------|
| face     | #C0C0C0 | фон панелей, кнопок, окон; заливка Raised/Pressed |
| light    | #FFFFFF | верхний/левый блик; заливка Sunken             |
| lighter  | #DFDFDF | второй блик                                    |
| shade    | #808080 | тень, неактивный текст, обводка Etched         |
| dark     | #0A0A0A | внешняя тёмная кромка (не чистый чёрный)       |
| select   | #000080 | выделение, заголовок активного окна            |
| text     | #000000 | текст                                          |

Бевели (тени перечислены как в CSS `box-shadow`, первая сверху; blur 0,
spread 0, непрозрачность 100 %; Figma рисует последний эффект массива
поверх, поэтому в коде порядок разворачивается):

| Пресет  | Заливка | Тени (x, y, цвет) сверху вниз                                  |
|---------|---------|----------------------------------------------------------------|
| Raised  | #C0C0C0 | inner −1,−1 #0A0A0A; 1,1 #FFFFFF; −2,−2 #808080; 2,2 #DFDFDF    |
| Sunken  | #FFFFFF | inner −1,−1 #FFFFFF; 1,1 #808080; −2,−2 #DFDFDF; 2,2 #0A0A0A    |
| Pressed | #C0C0C0 | inner −1,−1 #FFFFFF; 1,1 #0A0A0A; −2,−2 #DFDFDF; 2,2 #808080    |
| Etched  | нет     | обводка #808080 1 px inside + drop 1,1 #FFFFFF                  |

Прочие правила:

- Пиксель-перфект: целые координаты и размеры, бевели 1–2 px, никакого
  размытия и скруглений. Толщину бевела не масштабировать, это пиксель-арт.
- Сетка: Win95 — целые пиксели; Classic Mac в ките — U = 1,056 px.
- Шрифты: панель плагина — «MS Sans Serif» / «Pixelated MS Sans Serif» /
  Tahoma 11 px; кит — PP Mondwest, PP NeueBit (Mac), Inter (Win95).
  Шрифты в Figma не угадывать, брать из существующих слоёв.
- Именование: Effect Styles «Win95 / <name>»; имена слоёв несут поведение
  («— resize height freely», «— fills the rest», «— fills, truncates»,
  «— follows bar height», «REPLACE HERE»).
- Интерфейсные тексты плагина на русском («Выделите шейп», «Сбросить»).

## 4. Чего ещё нет (бэклог, согласовать с пользователем)

Айдентика канала как таковая не начата: есть инструмент и кит, нет
собранных носителей. Предлагаемый состав, приоритет уточнить:

1. Аватар канала: круглая обрезка Telegram, исходник не меньше 512×512.
   Варианты: иконка приложения в стиле System 7 или Win95, диалог «Warning»,
   дискета, замок.
2. Шаблоны картинок к постам 3–5 типов под жанры канала (предупреждение о
   скаме, разбор инцидента, инструкция, чек-лист, новость). Telegram сжимает
   фото до 1280 px по длинной стороне, поэтому макеты лучше собирать в
   1280×1280 или 1280×720 с крупной типографикой; точные требования
   Telegram проверить на момент работы.
3. Набор иконок 16×16 и 32×32 в духе Win95 / System 7 для рубрик и
   пиктограмм внутри окон.
4. Стикеры 512×512 и кастомные эмодзи 100×100 с интерфейсными элементами
   (кнопки OK/Cancel, курсор, песочные часы, иконка ошибки).
5. Типографическая и цветовая система поверх серой базы Win95: акцентные
   цвета для статусов (ошибка, предупреждение, успех), правила для
   заголовков, подписей и моноширинных блоков (адреса, хэши, команды).
6. Текстовая часть: название, описание канала, тон голоса, названия рубрик в
   терминах ОС (например «System Alert», «Patch Notes», «Read Me»).
7. Опционально: анимация (GIF-окна, курсор, прогресс-бар), обложки видео,
   закреплённый пост-навигатор.

Можно развивать плагин: пресеты Classic Mac (чёрная рамка 1 px, полосы
заголовка), Win95 title bar как компонент, пресет «Window» целиком.

## 5. Инструменты, которые понадобятся агенту в Projects

- Figma MCP (`mcp__Figma__*`): для любой работы в файле сначала
  `create_session` с fileKey, перед `use_figma` загрузить скилл
  `figma-use`; для сборки окон — скилл `brick`. Для установки плагина —
  скилл `figma-generative-plugins` и промт из `docs/mcp-install-prompt.md`.
- Плагин Retro Bevel в Figma: бевели ставить им, а не вручную, чтобы
  Effect Styles «Win95 / …» оставались едиными на весь файл.
- Генерация картинок (Higgsfield MCP или другой генератор), если подключён:
  только для референсов и фактур; интерфейсные элементы рисовать векторно в
  Figma, иначе пиксель-перфект не удержать.
- Репозиторий на GitHub: читать файлы по raw-ссылкам (раздел 7). Если нужны
  правки в коде плагина, делать их в сессии Claude Code с доступом к репо,
  а не в чате Projects.

## 6. Правила работы

- Не переписывать `code.ts` и `ui.html` без запроса пользователя: они
  проходят строгую сборку Figma; стиль Win95 в панели намеренный.
- В Figma работать на копиях рядом с оригиналом; мастер-компоненты и
  оригинальные фреймы менять только после явного «да».
- Временные тестовые фреймы удалять в том же скрипте. Ничего
  пользовательского не удалять.
- Не выдумывать факты о канале (название, аудитория, ссылки): их нет в этом
  документе, спросить.
- Отчёт после каждого шага в Figma: id созданных нод и размеры; если что-то
  схлопнулось в 0 или вылезло за границы, чинить сразу.
- Коротко, по-русски, без лишних вариантов. Сомнение, меняющее результат,
  задавать одним вопросом, остальное решать самому.
