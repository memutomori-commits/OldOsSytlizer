# Shader Presets — плагин Figma

Кнопка «сохранить пресет» для шейдеров Dither и CRT Display. Внутри шейдера Figma
кнопок не бывает, поэтому это отдельный плагин:

- **Код с выделенного слоя.** Выделяешь слой, плагин показывает Preset code для каждого
  шейдера на нём (с учётом выбранного пресета и сдвинутых слайдеров). Кнопка
  **Копировать** кладёт строку в буфер.
- **Применить код.** Вставляешь строку, нажимаешь **Применить**: значения записываются
  прямо в слайдеры всех выделенных слоёв, Preset сбрасывается на Custom, поле Preset
  code очищается, так что настройки сразу можно крутить дальше. Если на слое нет такого
  шейдера, плагин добавит его из библиотеки (галочка «Добавить шейдер, если его нет»).

Строка начинается с тега `shader=CRT Display` или `shader=Dither`: по нему плагин понимает,
в какой шейдер писать. Та же строка работает и в поле Preset code самого шейдера, тег он
просто пропускает.

В библиотеке аккаунта memut (с 2026-11-13) плагин под id `0f6a6cef-b906-4870-9ce7-fdb8593585cd`
(на старом аккаунте был `a4b6455f-8cab-4b11-a992-1fc9b9ac6f06`).
Обновить его из этого репозитория можно через Figma MCP `update_generative_plugin`
(файлы `code.ts` и `ui.html`), как описано для Retro Bevel в `docs/mcp-install-prompt.md`.
Для ручной установки: `npx tsc -p shader-presets/tsconfig.json`, затем Plugins →
Development → Import plugin from manifest… → `shader-presets/manifest.json`.

Таблица пресетов в `code.ts` вшивается из `shaders/presets.json` скриптом
`npm run bake-presets`, вместе с шейдерами.
