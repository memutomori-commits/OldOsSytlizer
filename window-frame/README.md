# Window Frame — плагин Figma (папка `window-frame/`)

Превращает выделенный прямоугольник в адаптивное окно-рамку в духе Windows:
бевель по периметру, тёмная плашка с редактируемым заголовком и кнопками «?» и «X»,
прозрачная середина — чтобы обвести человека или деталь на фото. Образец — слой
«Window — freely editable» (заголовок «WHO??») из Carousel Post / Explorer — 5 в файле
clubs_main. Сборщика нет: Figma читает `manifest.json`, `code.js` и `ui.html` как есть.

## Установка

Так же, как Retro Bevel: **Plugins → Development → Import plugin from manifest…** и
выберите `window-frame/manifest.json`. Или через Figma MCP как generative plugin:
файлы `window-frame/code.ts` и `window-frame/ui.html` передаются без изменений
(промт — в `docs/mcp-install-prompt.md`).

## Использование

1. Нарисуйте прямоугольник там, где нужна рамка (можно несколько), и выделите его.
2. Задайте заголовок, размер «пикселя» и нужные кнопки, нажмите **Собрать** (или Enter в поле заголовка).
3. Прямоугольник заменяется окном того же размера и положения (тот же родитель, тот же
   слой в списке, та же матрица, те же констрейнты, прозрачность и видимость).
   Сам прямоугольник удаляется; Ctrl/Cmd+Z возвращает его.

| Параметр | Что делает |
|----------|------------|
| Заголовок | Текст плашки. Дальше правится прямо на холсте — слой `Title — fills, truncates` |
| Пиксель, px | Единица пиксель-арта U. Все размеры кратны ей: бевель 2U, внутренняя тень 1U, плашка 18U, кнопка 18×15U, кегль 12U. В Carousel post U = 3.68, по умолчанию 4 |
| Кнопки ? и X | Какие кнопки класть в плашку; можно ни одной |

Последние параметры запоминаются (`clientStorage`). Каждое применение — отдельный шаг отмены.

## Что получается

Структура по скиллу brick (кирпичи снизу вверх, образец Window (Classic Mac)):

```
Window / <заголовок> — free resize      VERTICAL auto-layout, FIXED×FIXED, без заливки, clip
├ Title bar — resize height freely      HORIZONTAL auto-layout, W FILL, H FIXED 18U, градиент #000 → #571415
│ ├ Title — fills, truncates            Inter Regular 12U, #F7F7F7, W FILL, TRUNCATE
│ ├ Control button ? — follows bar height   H FILL + lock aspect ratio 18:15
│ └ Control button X — follows bar height
├ Content — fills the rest              FILL×FILL, прозрачный — сюда можно класть содержимое
└ Bevel / …                             6 absolute-прямоугольников на констрейнтах
```

- Отступы окна — толщина бевеля: 2U сверху и слева, 3U справа и снизу (2U тени + 1U внутренней).
- Внутри кнопки: тень и лицо STRETCH, бевель прижат к своему краю, глиф — SCALE/SCALE,
  поэтому растёт вместе с кнопкой. Глифы — пиксельные карты из `GLYPHS` в `code.ts`,
  снятые с векторов образца; рисуются одним `VectorNode` через `vectorPaths`.
- Минимумы окна: ширина 5U + 4U + 19U × кнопки + 8U, высота 31U. Меньше окно не сожмётся.

Как тянуть:

- **Окно** — за любой угол: плашка и бевель тянутся, середина берёт остаток.
- **Высота плашки** — у слоя `Title bar`: кнопки и глифы подстраиваются сами, кегль
  заголовка Figma не масштабирует — поправьте `fontSize` или воспользуйтесь Scale (K).
- **Заголовок** — двойной клик по тексту; длинный обрезается многоточием.

## Разработка

`npm run build` в корне репозитория собирает оба плагина (`code.ts → code.js` в корне
и в `window-frame/`). `code.ts` — строгий TypeScript с типами `@figma/plugin-typings`,
`ui.html` — обычный HTML без зависимостей, панель в Shadow DOM (как у Retro Bevel).
